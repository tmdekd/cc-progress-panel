## Review Focus

1. 끝난 단계 하나가 숨긴 예정과 보이는 단계 사이(덩어리를 나누지 않음)에 있으면 지금처럼 그려진다. → 기존 'a long list in a tall pane…' 테스트
2. 그리지 않는 묶음의 혼자 숨는 단계는 개수로 남는다(그리면 묶음 머리 줄이 는다). → Task 2 테스트
3. 목록 끝 묶음의 맨 끝 덩어리가 1개면 그 단계가 `└─`로 그려지고 앞 단계는 `├─`가 된다. → 바꾸는 기존 테스트
4. 가장 짧은 모양(one)에서는 맨 위 덩어리 하나라 묶음 안 규칙이 끼어들지 않는다. → 기존 'the shortest shape…' 테스트
5. `①②3`은 맨 앞 번호 규칙에 걸리지 않는다. → Task 3 테스트
