# cc-progress-panel

## 개요

- Claude Code 채팅 옆에 "진행 상황" 패널을 띄우는 mod
- 할 예정인 일, 지금 하는 일, 끝났거나 막힌 일을 단계 목록으로 보여 줌
- 단계 목록은 Claude가 일을 하면서 직접 적고 고침
- 여러 단계로 나뉘는 일이면 종류와 상관없이 씀(개발, 문서 작성, 조사, 설치·설정 등)

## 수동 호출 명령어

- `/progress`: 패널 열기·닫기
- `/progress clear`: 이 창의 진행 목록 지우기

## 기능

- 단계 표시: ● 완료 · ◉ 진행 중 · ○ 대기 · ▲ 막힘(이유 한 줄) · – 건너뜀
- 왼쪽 세로선으로 단계를 이음: 지나온 곳은 초록, 지금 묶음은 그 단계 색(진행 중 주황, 막힘 노랑), 남은 곳은 회색
- 묶음 아래에 단계 한 층까지 표시. 묶음 안 단계는 세로선에서 가지를 침(`├─◉ 메뉴 화면`, 목록 맨 끝 묶음의 마지막 단계는 `└─`)
- 원문자·로마 숫자(①, ⑴, Ⅳ 등)는 보통 글자로 바꿔 표시(`그림 ③` → `그림 3`, `④⑤` → `4,5`, `Task 1①` → `Task 1,1`, `그림 ③4` → `그림 3,4`). 글꼴이 2칸으로 그려 옆 글자를 덮는 일을 막음
  - 맨 앞 번호 하나 뒤에 빈칸이 오면 목록 번호로 표시(`❶ 자료 모음` → `1. 자료 모음`)
- 진행률: 제목 아래 한 줄 막대와 단계별 걸린 시간
  - 막대 옆에 완료 수와 전체 걸린 시간 표시(`━━━━──── 3/7 · 1시간 12분째`, 다 끝나면 `━━━━━━━━ 7/7 · 2시간 5분`)
  - 막대는 다 끝났을 때만 꽉 차고, 하나라도 끝났으면 한 칸은 채움. 패널이 아주 좁으면 걸린 시간을 뺌
  - 막 시작한 단계는 1분 동안 `방금 시작`으로 표시
  - Claude가 일한 시간만 셈. 일이 끝나고 다음 입력까지, 질문·계획 승인 창이 떠 있는 동안, 창이 꺼져 있던 동안은 뺌
  - 백그라운드로 띄운 명령·에이전트가 돌고 있으면 일하는 중으로 보고 셈(턴이 끝났거나 질문 창이 떠 있어도). 끝 알림을 받은 턴이 끝나면 다시 멈춤
- 짧게 보기: 지금 하는 일과 다음 할 일 중심
  - 진행 중·막힌 단계는 모두 표시
  - 끝난 단계는 가장 최근 1개만, 나머지는 `┆ 완료 n개 더`로 개수만 표시
  - 예정 단계는 3개까지만, 나머지는 숨긴 자리마다 `┆ 예정 n개 더`(묶음 안이면 `│ ┆ 예정 n개 더`)로 개수만 표시
  - 패널 높이에 여유가 있으면 예정 단계를 앞에서부터 하나씩 더 표시하고, 예정을 다 보인 뒤에도 남으면 끝난 단계를 최근에 끝난 것부터 더 표시
    - 이때 명령 줄(`▶ …`) 2줄 자리를 비워 두어, 명령이 생기고 없어져도 목록이 바뀌지 않음. 명령 줄이 3줄 이상이면 그만큼 줄임
  - 마지막 단계는 예정이어도 늘 표시해 일이 어디서 끝나는지 보임
  - 숨길 단계가 1개뿐이고 메모가 없으면 개수 대신 그 단계를 표시. 줄 수가 같을 때만 함
    - 예정 단계: 한 자리에 1개이고, 맨 위 단계(묶음 밖)이거나 이미 보이는 묶음 안의 단계
    - 끝난 단계: 통틀어 1개이고 맨 위 단계이며, 그려도 숨긴 예정의 개수 줄이 둘로 나뉘지 않을 때
  - 패널 높이가 모자라면 예정을 2개, 1개로 줄이고, 그다음 끝난 단계, 남은 예정 1개, 마지막 단계, 단계 사이 세로선 줄 차례로 빼고, 끝으로 숨긴 예정 개수를 맨 아래 한 줄로 합쳐 스크롤이 생기지 않게 함
- 알림: 단계가 끝나거나 막히거나 모든 단계가 끝나면 입력창 바로 위에 색 테두리 상자로 5초 동안 표시(완료는 초록, 막힘은 노랑)
- 돌고 있는 명령: 지금 1초 넘게 돌고 있는 명령을 진행 중 단계 바로 아래에 한 호출에 한 줄 `┆ ▶ 하는 일` 모양으로 붙임
  - 진행 중 단계가 여럿이면 가장 나중에 시작한 단계 아래에 표시. 막혔다가 다시 진행 중이 된 단계는 그때 시작한 것으로 봄
  - 진행 중 단계가 없으면 목록 맨 아래에 표시. 백그라운드 명령·에이전트는 표시하지 않음(시간 세기에만 씀)
  - 돌고 있는 명령이 없으면 아무것도 표시하지 않음
  - 5개까지 표시, 넘으면 `외 n개`. 같은 글(같은 파일을 두 번 읽는 등)은 한 줄로 합침
  - 파일·검색 도구는 종류(흐리게)와 대상을 함께 표시
    - `▶ 읽기 db/load.py:120-199`: 폴더/파일과 읽는 줄 범위
    - `▶ 수정 ai/agent.py`, `▶ 작성 me/notes.md`
    - `▶ 검색 "SESSION_RE" · db`: 찾는 말과 범위(경로, 없으면 glob·type). 경로가 `.`·`..`·`~`·드라이브(`C:`)뿐이면 없는 것으로 봄
    - `▶ 찾기 **/*.tsx · web`, `▶ 웹 검색 "빵집"`, `▶ 웹 페이지 example.com`
  - 폭이 모자라면 폴더, 줄 범위 차례로 빼고, 그래도 넘치면 끝을 자름
  - MCP 도구는 도구 이름만, 스킬은 `▶ 스킬 이름`으로 표시
- 목록 저장: 폴더·창별로 저장. 다시 켜면 같은 대화의 목록을, 없으면 같은 폴더에서 꺼진 창의 최근 목록을 이어받음. `/resume`으로 다른 대화로 돌아가면 그 대화의 목록으로 바뀜
- 패널이 저절로 열리는 때: Claude가 새 단계 목록을 적을 때, 창을 켤 때 이어받은 목록이 아직 안 끝났을 때
- 화면 폭
  - 터미널 전체 화면 레이아웃에서 110칸 이상이면 오른쪽에 붙고, 그 밖에는 입력창 위에 뜸
  - 저절로 열리는 것은 144칸 이상일 때만. 좁으면 `/progress`로 직접 열기

## 설치 방법

- Claude Code 입력창에서:

  ```
  /plugin install progress-panel --marketplace tmdekd/cc-progress-panel
  ```

  - `Add marketplace?`에 `y`
  - 설치 범위는 user를 고르고 Enter
  - `Installed progress-panel. Plugin is now active.`가 뜨면 끝. 그 창부터 바로 동작

- 셸에서:

  ```
  claude plugin install progress-panel --marketplace tmdekd/cc-progress-panel
  ```

- 데스크톱 앱에서: 입력창 옆 + → Plugins → Add marketplace에 `tmdekd/cc-progress-panel` 입력 → Add plugin

- 업데이트: main에 새 커밋이 올라올 때마다 새 버전이 됨
  - 자동 업데이트는 기본으로 꺼져 있음(Anthropic 공식 마켓플레이스가 아니라서). 켜려면 입력창에서 `/plugin` → Marketplaces → `cc-progress-panel` → Enable auto-update. 켜 두면 Claude Code를 켤 때 새 버전을 받음
  - 직접 받으려면 셸에서:

    ```
    claude plugin update progress-panel@cc-progress-panel
    ```

  - 받은 뒤 `/reload-plugins`를 실행하거나 Claude Code를 다시 켜면 적용
