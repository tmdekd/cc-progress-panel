# cc-progress-panel
Claude Code를 사용 시 '/progress' 명령어를 사용하여 우측에 사이드 패널이 생성되어, 진행중인 사항에 대하여 확인하고 진행정도와 사항들을 확인 가능하다.

채팅 옆 "진행 상황" 패널에 지금 하는 일의 전체 단계, 지금 단계, 지금 돌고 있는 일을 보여 주는 Claude Code mod.

## 설치

Claude Code 터미널의 입력창에서:

```
/plugin install progress-panel --marketplace tmdekd/cc-progress-panel
```

마켓플레이스를 추가할지 물으면 `y`, 이어서 설치 범위를 고른다. 비공개 저장소라서 저장소에 초대받아 있어야 하고, 그 컴퓨터에서 git이 GitHub에 로그인되어 있어야 한다.

셸에서:

```
claude plugin install progress-panel --marketplace tmdekd/cc-progress-panel
```

## 하는 일

- 단계 목록은 Claude가 `mcp__progress-panel__progress` 도구로 적고 고친다(단계 3개 이상인 일, 계획 문서 작업, 자리를 비운 동안의 자율 작업). 규칙은 mod가 시스템 프롬프트에 붙인다.
- 표시: ✓ 끝 · ▶ 진행 중 · · 대기 · ⚠ 막힘 · – 건너뜀, 진행률 막대, 단계별 걸린 시간.
- 알림: 단계가 끝나거나 막히거나 모든 단계가 끝나면 입력창 바로 위에 색 테두리 상자(끝은 초록, 막힘은 노랑)로 5초 동안 띄운다. 기본 알림창(`$.ui.toast`)은 쓰지 않는다. 입력창 위에 질문(설문)이 떠 있으면 그동안은 그리지 않는다.
- 실행 중 칸: 메인 대화에서 1초 넘게 도는 호출을 `- 하는 일` 목록으로 보여 준다(머리말·걸린 시간 없음, 백그라운드도 같은 모양). Bash·PowerShell은 Claude가 붙인 한국어 설명(description)을, 설명이 없으면 앞의 `cd 경로 &&`를 떼고 첫 명령만(뒤의 `|`·`&&`·`;`·출력 돌리기 없이), 절대 경로는 마지막 이름만 남겨 보여 준다. 설명을 한국어로 짧게 적으라는 규칙도 시스템 프롬프트에 붙인다.
- 목록은 폴더와 창(세션)별로 `$.store`에 저장된다. 다시 켜면 같은 세션 목록, 없으면 꺼진 창(3분 넘게 소식 없음)의 가장 최근 목록을 이어받는다. 켜져 있는 다른 창의 목록은 건드리지 않는다.
- `/progress`: 패널 열기·닫기, `/progress clear`: 이 창의 목록 지우기.
- 패널은 터미널 전체 화면 레이아웃에서 110칸 이상이면 오른쪽에 붙고, 그 밖에는 입력창 위에 뜬다. 저절로 열리는 것은 144칸 이상일 때만이다.

확인: `claude plugin validate .`, `claude plugin test .`
